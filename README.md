## GitHub Pages

1. Create a repository named `MateusLima30.github.io` under the GitHub account `MateusLima30`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save. The site should publish at `https://MateusLima30.github.io`.

## Updating the site

Edit the HTML files in GitHub, then commit the change. GitHub Pages will rebuild the site automatically.
